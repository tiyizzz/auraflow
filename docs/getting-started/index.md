# AURAFLOW 快速开始

AURAFLOW R1 系列热风烘豆机安装简单，三步即可完成。

## 1. 开箱检查

确认配件齐全：

| 配件 | R1 标准款 | R1 Pro 专业款 |
|------|-----------|---------------|
| 主机 | 1 台 | 1 台 |
| 豆仓 | 1 个（1.5 kg） | 1 个（2.5 kg） |
| 收集杯 | 1 个 | 1 个 |
| 电源线 | 1 根（220V） | 1 根（220V） |
| 陶瓷内胆 | 1 个 | 1 个 |
| 清洁刷 | 1 把 | 1 把 |
| 快速指南 | 1 份 | 1 份 |

> 如有配件缺失，请联系官方客服。

## 2. 组装

1. 将陶瓷内胆轻轻放入加热仓
2. 安装豆仓，旋紧锁扣
3. 放置收集杯于出料口下方
4. 连接电源线

> 注意：不要用手直接触碰陶瓷内胆表面。

## 3. 开机配网

1. 长按电源键 3 秒开机
2. 屏幕显示设备热点名称（如 `CHAVAL-A1B2C3`）
3. 手机/电脑连接该热点
4. 浏览器自动弹出配网页面，或手动访问 `192.168.4.1`
5. 选择你的 WiFi 网络并输入密码
6. 等待连接成功提示

## 4. 首次烘焙

1. 打开浏览器访问设备 IP 地址
2. 进入「曲线」页面，选择默认浅烘曲线
3. 预热加热仓至目标温度
4. 入料（倒入生豆）
5. 观察实时温度曲线，等待烘焙完成
6. 冷却 90 秒后取出豆子

> 首次使用建议先用默认浅烘曲线熟悉操作，逐步调整参数找到适合你豆子的最佳曲线。

## 5. 日常维护

- 每次使用后清洁陶瓷内胆和收集杯
- 定期检查散热口是否通畅
- 避免在潮湿环境中长时间存放
