## 如何使用

在 **曲线** 页面浏览这些烘焙曲线的可视化预览，也可以直接在 [Artisan](https://artisan-scope.org/) 中打开 `.alog` 文件进行详细分析。

## 文件格式

`.alog` 文件为 Artisan 的单行 Python dict 序列化格式，包含：

- `timex` — 时间轴（秒，相对烘焙开始）
- `temp1` — BT 豆温曲线
- `temp2` — ET 排气温度曲线
- `phases` — 关键事件时间点（入料/干燥/一爆/出炉）
- `computed` — 自动计算的统计数据（AUC、阶段时长等）

详细结构分析见 [`alog/STRUCTURE_ANALYSIS.md`](../../alog/STRUCTURE_ANALYSIS.md)。
