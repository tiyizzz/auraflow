# AURAFLOW R1 硬件组装指南

本文档描述 R1 标准款和 R1 Pro 专业款的硬件组装步骤与注意事项。

## 1. 产品概览

## 2. 安全须知

- 组装前断开电源
- 陶瓷内胆高温易碎，操作时轻拿轻放
- 不要用手直接触碰陶瓷内胆表面
- 确保散热口通畅，设备放置在平稳耐热的台面上
- 非专业人士请勿拆解加热元件和电路板

## 3. 组装步骤

### 步骤 1：准备组件

打开包装箱，确认所有配件齐全（参考开箱检查清单）。

### 步骤 2：安装陶瓷内胆

1. 将加热仓放在平稳的台面上
2. 取出陶瓷内胆，观察是否有裂纹
3. 将陶瓷内胆轻轻放入加热仓，确保底部平整贴合

### 步骤 3：安装豆仓

1. 将豆仓对准加热仓顶部
2. 顺时针旋转锁扣，听到咔哒声表示已锁定
3. 拉动豆仓手柄确认安装牢固

### 步骤 4：安装收集杯

1. 将收集杯插入出料口
2. 确保收集杯卡入到位

### 步骤 5：连接电源

1. 将电源线插入设备背部接口
2. 确认电源线另一端连接至 220V 市电

## 4. 接线说明

### 电源模块

- 输入：220V AC / 50Hz
- 输出：24V DC 至主控板

### 传感器接线

| 传感器 | 接口 | 说明 |
|--------|------|------|
| 豆温传感器（PT100） | J1 | 插入加热仓顶部 |
| 排温传感器（PT100） | J2 | 插入加热仓排气口 |
| 热风温度传感器 | J3 | 风道出口处 |

### 执行器接线

| 执行器 | 接口 | 说明 |
|--------|------|------|
| 加热管 | H1 | 陶瓷内胆加热元件 |
| 变频风机 | FAN1 | 热风循环风扇 |
| 冷却风扇 | FAN2 | 出料口冷却风扇 |

## 5. 传感器校准

首次使用或更换传感器后需要进行温度校准。

### 校准方法

1. 进入设备 Web 界面 → 配置 → 校准
2. 使用校准过的温度计测量实际温度
3. 输入偏移量：负值降低读数，正值升高读数
4. 点击「应用」保存

### 校准参考

| 校准温度 | 允许偏差 |
|----------|----------|
| 160°C | ±2°C |
| 200°C | ±2°C |
| 220°C | ±1°C |

## 6. 常见问题

**Q: 陶瓷内胆破裂怎么办？**

A: 停止使用，联系官方客服更换备件。不要继续加热有裂纹的内胆。

**Q: 温度读数不准？**

A: 检查传感器是否正确插入，进入校准页面调整偏移量。

**Q: 风机不转？**

A: 检查风机接线是否松动，确认电源电压正常。

**Q: 设备无法配网？**

A: 确认 WiFi 密码正确，设备与路由器距离不要太远（建议 5 米内）。
