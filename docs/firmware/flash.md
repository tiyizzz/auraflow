# AURAFLOW 固件刷写指南

本文档说明如何通过浏览器为 AURAFLOW R1 设备刷写固件。

## 1. 固件来源

固件文件（`.bin`）通过以下方式获取：

### 方式一：GitHub Releases（推荐）

1. 访问 [AURAFLOW GitHub Releases](https://github.com/auraflow/auraflow/releases)
2. 下载最新版本的 `.bin` 固件文件
3. 记录下载 URL，用于在线刷机页面

### 方式二：手动输入 URL

如果 GitHub 不可访问，可以从其他来源获取固件 URL。

### 方式三：本地上传

直接将 `.bin` 文件从本地磁盘上传到刷机页面。

## 2. 在线刷机步骤

1. 确保设备已连接到同一局域网
2. 打开浏览器，访问 `http://<设备IP>/flash`
3. 选择固件来源：
   - **URL 下载**：输入固件文件的 HTTP URL
   - **本地上传**：点击上传按钮，选择 `.bin` 文件
4. 点击「开始刷机」
5. 等待进度条走完（约 2-3 分钟）
6. 刷机完成后设备会自动重启

## 3. 注意事项

- 刷机过程中请勿断电或关闭浏览器页面
- 整个刷机过程约需 2-3 分钟，请耐心等待
- 如果刷机失败，设备会自动回滚到上一版本
- 刷机完成后可以在设备信息页面验证固件版本

## 4. 故障排查

**Q: 刷机失败怎么办？**

A: 检查网络连接是否稳定，重新尝试刷机。如果多次失败，请联系技术支持。

**Q: 刷机后设备无法启动？**

A: 设备具备安全回滚机制，长按重置键恢复出厂设置后重新刷机。

**Q: 固件版本不兼容？**

A: 确保下载的固件版本与你的硬件型号匹配（R1 标准款 vs R1 Pro 专业款）。
